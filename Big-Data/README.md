# Big Data

Big Data covers deployment, operations, governance, analytics, and AI-ready data foundations for enterprise data platforms on Huawei Cloud.

> **For migration of databases and data platforms to Huawei Cloud**, see [Database-Migration](../Application-Modernization/Database-Migration/README.md).

## Categories

- [Big Data Platform Deployment](./Big-Data-Platform-Deployment/README.md): Deploy big data platform pipelines on Huawei Cloud, including the [MRS DWS Finance Skill](./Big-Data-Platform-Deployment/MRS-DWS-Finance-Skill/README.md) for financial risk control with OBS, MRS, and DWS.
- [Data Warehouse Deployment](./Data-Warehouse-Deployment/): Deploy data warehouse infrastructure on Huawei Cloud DWS. (Skills to be added.)
- [Huawei Big Data Deployment](./Huawei-Big-Data-Deployment/README.md): Generate Terraform code for deploying MRS, DWS, DLI, OBS, CDM, DataArts, and VPC infrastructure with reusable modules.
- [Data Governance](./Data-Governance/README.md): Establish standards, quality, metadata, security, and asset management across data environments.
- [ChatBI and Intelligent Analytics](./ChatBI-and-Intelligent-Analytics/README.md): Enable conversational BI, metric question answering, and automated analysis generation.
- [AI Knowledge Base](./AI-Knowledge-Base/README.md): Build the structured and unstructured data foundation needed for RAG and model consumption.
- [Huawei Cloud SEC EDGAR Big Data POC](./Huawei%20Bigdata%20Real%20E2E%20Process%20monitoring/README.md): Reproduce and operate an end-to-end Huawei Cloud big-data monitoring PoC across OBS, MRS Spark, DWS, Superset, ECS, and a public lifecycle-monitoring website.
