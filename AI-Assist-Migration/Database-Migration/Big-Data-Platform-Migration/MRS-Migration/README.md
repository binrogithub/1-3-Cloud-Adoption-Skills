# MRS Migration

Migrate complete big-data systems — components and internal data — from on-premises Hadoop distributions (Apache Hadoop, CDH, Hortonworks, FusionInsight), AWS (EMR/S3), Azure (HDInsight/Blob Storage), or Google Cloud (Dataproc/Cloud Storage) into Huawei Cloud MapReduce Service (MRS) CUSTOM clusters.

## Skills

| Skill | Purpose |
|---|---|
| [huawei-mrs-migration-operations](./huawei-mrs-migration-operations/) | Migrate big-data systems to MRS using hcloud CLI (KooCLI). Three planes: OMS bulk object migration, MRS DistCp data load, Hive metadata rebuild. |
