# Database Usage Operations

## Purpose

Use already-deployed Huawei Cloud database instances — RDS, DDS, GeminiDB, TaurusDB, and GaussDB — via hcloud CLI (KooCLI): find an instance, read its connection details, and assign it an Elastic IP (EIP) for public access.
