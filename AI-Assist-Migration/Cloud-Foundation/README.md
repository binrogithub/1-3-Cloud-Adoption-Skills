# Cloud Foundation

This directory covers the foundational cloud setup and operations that enable migration and modernization workloads.

## Scenarios

| Directory | Description |
|---|---|
| [Automation-and-IaC](./Automation-and-IaC/) | Automation scripts, Terraform IaC, and CLI tooling for standardized cloud operations |
| [Landing-Zone-and-Organization-Management](./Landing-Zone-and-Organization-Management/) | Multi-account landing zone design, organization governance, IAM, and Identity Center |
| [Operations-AIOps-and-Tool-Interconnection](./Operations-AIOps-and-Tool-Interconnection/) | Operational excellence, AIOps, alert governance, and third-party tool integration |
| [DR-and-Backup](./DR-and-Backup/) | Backup strategy, disaster recovery design, failover planning, and continuity exercises |
| [AWS-CloudFormation-to-RFS](./AWS-CloudFormation-to-RFS/) | Migrate AWS CloudFormation templates to Huawei Cloud RFS (Resource Formation Service) |
| [AWS-CloudWatch-to-Huawei-CES](./AWS-CloudWatch-to-Huawei-CES/) | Migrate AWS CloudWatch alarms and dashboards to Huawei Cloud CES (Cloud Eye Service) |
| [AWS-IAM-to-Huawei-IAM](./AWS-IAM-to-Huawei-IAM/) | Migrate AWS IAM users, roles, and policies to Huawei Cloud IAM |
| [AWS-KMS-to-Huawei-DEW](./AWS-KMS-to-Huawei-DEW/) | Migrate AWS KMS keys and encryption to Huawei Cloud DEW (Data Encryption Workshop) |
| [AWS-VPC-to-Huawei-VPC](./AWS-VPC-to-Huawei-VPC/) | Migrate AWS VPC, subnets, and security groups to Huawei Cloud VPC |
