# Object Migration

This directory covers skills and tools for migrating object storage data to Huawei Cloud OBS (Object Storage Service).

## Contents

- [huaweicloud-oms-migration](./huaweicloud-oms-migration/) — Object Storage Migration Service (OMS) skill for migrating data from source clouds or on-premises to Huawei Cloud OBS.
- [AWS-S3-to-Huawei-OBS](./AWS-S3-to-Huawei-OBS/) — Migrate AWS S3 buckets and objects to Huawei Cloud OBS using floci local emulator and hcloud MCP.
- [Azure-Blob-to-Huawei-OBS](./Azure-Blob-to-Huawei-OBS/) — Migrate Azure Blob Storage containers to Huawei Cloud OBS using floci-az local emulator and hcloud MCP.
- [GCP-GCS-to-Huawei-OBS](./GCP-GCS-to-Huawei-OBS/) — Migrate Google Cloud Storage buckets to Huawei Cloud OBS using floci-gcp local emulator and hcloud MCP.
