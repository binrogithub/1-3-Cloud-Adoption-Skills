# Virtual Machine Migration

This directory covers skills and tools for migrating virtual machines and server workloads to Huawei Cloud ECS.

## Contents

- [huaweicloud-sms-migration](./huaweicloud-sms-migration/) — Server Migration Service (SMS) skill for migrating on-premises or cloud VMs to Huawei Cloud ECS.
- [Vmware-Migration](./Vmware-Migration/) — VMware to Huawei Cloud migration guidance and references.
- [AWS-EC2-to-Huawei-ECS](./AWS-EC2-to-Huawei-ECS/) — Migrate AWS EC2 instances to Huawei Cloud ECS using floci local emulator and hcloud MCP.
- [Azure-VM-to-Huawei-ECS](./Azure-VM-to-Huawei-ECS/) — Migrate Azure VMs to Huawei Cloud ECS using floci-az local emulator and hcloud MCP.
- [GCP-GCE-to-Huawei-ECS](./GCP-GCE-to-Huawei-ECS/) — Migrate Google Compute Engine instances to Huawei Cloud ECS using floci-gcp local emulator and hcloud MCP.
