⚠️ Disclaimer Central

Lee con atención antes de continuar con la sesión.

Nota Central: Esta sesión presenta las capacidades asistidas por IA de Huawei Cloud MaaS y sus ideas de aplicación para migrar VMs de nube a ECS. No procesa datos reales de clientes ni constituye un plan formal de entrega, compromiso de seguridad o cumplimiento, ni promesa de funciones del producto.
1

Datos y Privacidad

Seguridad / Cumplimiento / Protección
  • No se recopilan ni procesan datos reales del cliente
  • Use datos simulados, de prueba o anonimizados
  • No cargue cuentas, contraseñas, claves, certificados ni datos
2

Límites de Uso

Referencia / Revisión Humana
  • La IA apoya planificación, análisis, scripts y riesgos
  • No reemplaza diseño, revisión experta, pruebas ni decisiones
  • Revise planes, scripts y configuraciones antes del proyecto
3

Autorización del Cliente

Autorización / Aprobación
  • El cliente decide si usa IA en proyectos reales
  • Sin autorización, no ingrese información del cliente en IA
  • Respete seguridad, cumplimiento, confidencialidad y aprobaciones
4

Escenarios No Recomendados

Evaluación Prudente / Proceso Manual
  • Evalúe o evite escenarios de seguridad muy sensible
  • Sistemas clasificados, núcleo financiero, defensa o energía
  • Use migración manual ante soberanía estricta o prohibición de IA
La migración asistida por IA mejora la eficiencia; no sustituye la revisión humana ni la autorización del cliente. La implementación real debe basarse en la confirmación del cliente, seguridad, cumplimiento y situación del proyecto.

Glosario Exprés

5 conceptos clave en menos de 1 minuto.

Modelo

Modelo

IA entrenada con miles de millones de parámetros que predice texto. Es el "cerebro" que razona y genera respuestas.

Token

Token

Unidad mínima de texto (palabra o fragmento) que el modelo procesa. El costo y el contexto se miden en tokens.

Agente

Agente

IA que recibe un objetivo, razona pasos, usa herramientas y actúa de forma autónoma hasta completar la tarea.

MCP

MCP

Protocolo que conecta al agente con herramientas y datos externos (APIs, CLI, nube) de forma estandarizada.

Skill

Skill

Paquete de instrucciones + flujos + referencias que convierte al agente en especialista de un dominio concreto.

Demo: Arquitectura WordPress

Migración de una arquitectura WordPress estándar de AWS a Huawei Cloud. EC2 → ECS · RDS AWS → RDS Huawei Cloud · VPC, subnets y security groups equivalentes.

☁️ Antes — AWS Estado actual
Arquitectura: WordPress en EC2 (subnet pública, EIP) + RDS MySQL (subnet privada). SG-Web permite 80/443 desde Internet; SG-DB permite 3306 sólo desde SG-Web.
☁️ Objetivo — Huawei Cloud Migración asistida por IA
Arquitectura objetivo: WordPress en ECS (subnet pública, EIP) + RDS MySQL Huawei Cloud (subnet privada). SG equivalentes. Mismas reglas de firewall, CIDRs y topología de red.
