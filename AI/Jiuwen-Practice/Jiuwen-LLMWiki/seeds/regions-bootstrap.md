# LATAM regions — bootstrap digest

Bootstrap digest 2026-09-24 (see seeds/README.md). Region NAMES only; availability-zone
counts and the authoritative service x region matrix are intentionally excluded until
the authoritative source decision OQ-1 is resolved (PRD GL-K4: the region list must be
loaded from an authoritative source, never typed by hand or generated by an LLM; this
digest is a stopgap that a curator must replace).

Huawei Cloud operates LATAM regions named LA-Sao Paulo1, LA-Santiago, LA-Mexico City1
and LA-Mexico City2. LA-Sao Paulo1 serves Brazil from Sao Paulo. LA-Santiago serves
Chile and the Andean market from Santiago. LA-Mexico City1 and LA-Mexico City2 serve
Mexico. Object Storage Service (OBS) is available in LA-Sao Paulo1. Each region has
its own endpoints of the form <service>.<region>.myhuaweicloud.com.
