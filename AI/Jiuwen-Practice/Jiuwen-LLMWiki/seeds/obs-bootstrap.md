# Object Storage Service (OBS) — bootstrap digest

Bootstrap digest 2026-09-24 (see seeds/README.md; replace with a curator-pulled
snapshot before pilot). Source of facts: public Huawei Cloud OBS documentation.

Object Storage Service (OBS) is Huawei Cloud's object storage service. OBS provides
storage classes named Standard, Infrequent Access and Archive. A single object stored
in OBS can be up to 48.8 TB in size. Buckets in OBS are named with globally unique
DNS-compliant names. OBS buckets are accessed over HTTPS through endpoints of the form
obs.<region>.myhuaweicloud.com, for example obs.la-south-1.myhuaweicloud.com. OBS is
available in the LATAM region LA-Sao Paulo1. The OBS management console, APIs, SDKs,
tools and third-party ecosystem are documented on the Huawei Cloud international
documentation site, and OBS product pages live under www.huaweicloud.com/intl/en-us/product/obs.html.
